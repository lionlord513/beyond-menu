# 0.1.0

- First standalone BeyondMenu release, opened with F8.
- New rounded, transparent interface and saved color settings.
- Native item data, icons, search, custom spraypaint and unlimited supplies.
- Stock and tuned vehicle pictures, delayed hover preview, a car color wheel with metallic/matte finishes and native car spawning.
- Bright vehicle thumbnails with complete stock/tuned paint bases. Visible icons update first in the background without rebuilding the page or clearing search.
- Host scoreboard actions, including the native owning-client teleport route.
- Optional item providers for separately installed Beyond Apocalypse and Beyond Tuning; Hornet, motorcycles and trailer appear only in the car spawner.
- GitHub update metadata and a standalone checksum-verified updater.
